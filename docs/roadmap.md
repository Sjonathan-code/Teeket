# Feuille de route MVP

## Phase 1 - Fondation

- Monorepo, base PostgreSQL, schéma Prisma
- Guards d'authentification, de tenant et de rôles
- Pages web de départ
- CI et documentation

## Phase 2 - Support essentiel

- Authentification complète
- CRUD organisations, utilisateurs et memberships
- CRUD tickets, commentaires et assignation
- Inventaire machines initial
- Journalisation d'audit

## Phase 3 - Assistance intelligente

- Résumé et qualification IA avec validation humaine
- Base de connaissance
- Premier agent machine sécurisé
- Playbooks de diagnostic en lecture seule

## Phase 4 - AutoFix encadré

- Worker d'exécution isolé
- Catalogue d'actions autorisées
- Approbation, observabilité et rollback lorsque possible
